# 儲互社選務勇者傳：奪回大圖記！

依 **115.10.03 最新版中華民國儲蓄互助社法規彙編**（選舉罷免辦法、章程範例、設立輔導管理與監督辦法及幹部移交實務）打造的奇幻繪本互動 RPG 學習遊戲。

## 遊戲特色
- **六大奇幻小鎮據點（18 回合實戰對決）**：涵蓋 115.02.25 章程第 17 條欠費抵充、115.01.13 核備監督辦法第 24 條、留置股金四步驟、二親等與專職迴避、委託書禁令、限制連記折半、13 款無效票、三級選務與罷免、首次理監事會與抗不移交刑責（儲互社法第 32 條）。
- **六座互動移交清冊寶箱**：完整收錄印信、未完成案件、檔案、財務、人事、財產六大移交清冊要點。
- **零門檻即開即玩**：純靜態 HTML + WebP 輕量化資產，支援電腦、平板與手機 LINE 瀏覽器、中文語音朗讀、內建繪本配樂、大字模式、自動存檔與可列印榮譽合格證書。
