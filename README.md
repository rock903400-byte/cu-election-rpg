# 儲互社選務勇者傳：奪回大圖記！

依 **115.10.03 最新版中華民國儲蓄互助社法規彙編**（選舉罷免辦法、章程範例、設立輔導管理與監督辦法及幹部移交實務）打造的奇幻繪本互動 RPG 學習遊戲。

## 遊戲特色
- **六關選務值班**：社員送件、候選人資格、投票現場紀錄、開票選票、罷免案、移交清冊一件件上門，依規定判斷（受理／退件、合格／不合格、合規／違規、有效／作廢、合法／不合法、正確／退回）；同事寫的說法判斷「沒問題／要糾正」；每關最後由魔王出牌出題。每件只能判一次，判錯當場開糾正單、扣 1 點公信力，5 點扣光就重辦該關（卡冊、星等、存檔保留）；20 秒內判完有快手加分，慢慢看不扣公信力。文件每次隨機換成合格版或不合格版，重玩不能背答案。涵蓋候選人登記與連署、115.02.25 章程第 17 條欠費抵充、理監事法定員額與候補 1/3、理2監1 資格審查與複審、二親等與專職迴避、委託書禁令、成會門檻、限制連記折半、票數核對與票匭加封、13 款無效票、異議與簡歷冊期限、首次理監事會、三級任期與連任限制、出缺遞補與補選、罷免門檻、當場移交與一式四份清冊、報備與變更登記、抗不移交刑責（儲互社法第 32 條）。
- **前五關任選，最後才是最終決戰**：前五關（登記、資格審查、社員大會、開票、任期與罷免）順序自己挑；五關都過了，第 6 關「幹部移交」最終決戰才開放。六關都過才能領榮譽合格證書。已過的關隨時可以再玩。
- **📘 選務手冊**：每關會用到的規定隨時可翻，條文依 115.10.03 法規彙編原文。
- **六大移交清冊互動點交卡**：印信、未完成案件、檔案、財務、人事、財產六大清冊逐項點交核對＋20 秒快問快答，答對才入庫；收齊 3 冊，最終關有「清冊佐證」（魔王難題先刪一張錯牌、第一次判錯不扣公信力）；收齊六冊，最終關過關時發動「合法點交大陣」，證書加蓋「完美清冊制霸印記」。
- **法規卡冊＋🔑 重點**：每完成一關值班，這一關的法規牌收進「法規卡冊」，附一行重點與完整講解，可隨時翻開複習，曾判錯的題型會標記「建議複習」。
- **選務全流程時間軸 SOP 總圖**：從選前候選人登記到選後移交、報備與變更登記六大階段，每破一關自動點亮。
