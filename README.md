# 儲互社選務勇者傳：奪回大圖記！

依 **115.10.03 最新版中華民國儲蓄互助社法規彙編**（選舉罷免辦法、章程範例、設立輔導管理與監督辦法及幹部移交實務）打造的奇幻繪本互動 RPG 學習遊戲。

## 遊戲特色
- **六大奇幻小鎮據點（24 回合、四種題型）**：每關輪流出現「三選一出牌」「找碴（抓廢票、審申請書與名冊、查選務紀錄、驗移交清冊）」「合法／違規快判」「數字牌」，答錯只說明錯在哪，每關依答錯次數給 1～3 顆星。涵蓋候選人登記與連署、115.02.25 章程第 17 條欠費抵充、理監事法定員額與候補 1/3、理2監1 資格審查與複審、二親等與專職迴避、委託書禁令、成會門檻、限制連記折半、票數核對與票匭加封、13 款無效票、異議與簡歷冊期限、首次理監事會、三級任期與連任限制、出缺遞補與補選、罷免門檻、當場移交與一式四份清冊、報備與變更登記、抗不移交刑責（儲互社法第 32 條）。
- **六大移交清冊互動點交卡**：印信、未完成案件、檔案、財務、人事、財產六大清冊逐項點交核對＋20 秒快問快答，答對才入庫；收齊六冊可在最終魔王戰發動「合法點交大陣」，證書加蓋「完美清冊制霸印記」。
- **法規卡冊＋🔑 重點**：每回合過關後的法規牌收進「法規卡冊」，附一行重點與完整講解，可隨時翻開複習，曾答錯的題目會標記「建議複習」。
- **選務全流程時間軸 SOP 總圖**：從選前候選人登記到選後移交、報備與變更登記六大階段，每破一關自動點亮。
- **零門檻即開即玩**：純靜態 HTML + WebP 輕量化資產，支援電腦、平板與手機 LINE 瀏覽器、中文語音朗讀、內建繪本配樂、三段字級（標準／大／特大）、自動存檔與可列印榮譽合格證書。
