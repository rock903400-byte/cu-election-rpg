# 儲互社選務勇者傳：奪回大圖記！

依 **115.10.03 最新版中華民國儲蓄互助社法規彙編**（選舉罷免辦法、章程範例、設立輔導管理與監督辦法及幹部移交實務）打造的奇幻繪本互動 RPG 學習遊戲。

## 遊戲特色
- **六大奇幻小鎮據點（24 回合實戰對決）**：涵蓋 115.02.25 章程第 17 條欠費抵充、115.01.13 核備監督辦法第 24 條、留置股金四步驟、候選人登記與連署、理2監1 資格審查與複審、二親等與專職迴避、理監事法定員額與候補 1/3、委託書禁令、限制連記折半、票數核對與票匭加封、13 款無效票、三級選務與罷免、出缺遞補與補選、理事長連任限制、首次理監事會與抗不移交刑責（儲互社法第 32 條）。
- **六大移交清冊互動點交卡**：印信、未完成案件、檔案、財務、人事、財產六大清冊逐項點交核對＋10 秒快問快答，答對才入庫；收齊六冊可在最終魔王戰發動「合法點交大陣」，證書加蓋「完美清冊制霸印記」。
- **選務全流程時間軸 SOP 總圖**：從選前候選人登記到選後移交、報備與變更登記六大階段，每破一關自動點亮。
- **零門檻即開即玩**：純靜態 HTML + WebP 輕量化資產，支援電腦、平板與手機 LINE 瀏覽器、中文語音朗讀、內建繪本配樂、三段字級（標準／大／特大）、自動存檔與可列印榮譽合格證書。
